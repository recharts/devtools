Freeform annotations are allowed anywhere on the chart.
They use pixel coordinates and are not bound to data points.

Freeform coordinates use either native SVG elements, or Recharts shapes that accept pixel coordinates:

- SVG elements: `<line>`, `<rect>`, `<circle>`, etc.
- Recharts shapes: `<Cross>`, `<Dot>`, `<Rectangle>`, `<Sector>`, etc.
